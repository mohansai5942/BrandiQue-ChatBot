# BrandiQue ChatBot

Premium AI customer-support chatbot for BrandiQue Web Solutions.

## Stack
- Vanilla HTML/CSS/JS frontend
- Node.js + Express backend
- OpenRouter-compatible chat completion API
- Helmet + rate limiting
- Railway-ready

## Local setup
1. `npm install`
2. Copy `.env.example` to `.env`
3. Add your OpenRouter API key
4. `npm start`
5. Open `http://localhost:3000`

## Deployment
Deploy the repository to Railway as a Node.js service. Add the environment variables from `.env.example` in Railway Variables.

API keys must never be committed to GitHub.
